# Smart Road Pothole Detection System 🚗

## Project Overview
An IoT-based system designed to detect potential road potholes using sensors and GPS.

## Components
- ESP32
- MPU6050 Accelerometer
- NEO-6M GPS Module
- Power Supply

## Working
The MPU6050 detects changes in vehicle movement. ESP32 processes sensor readings, while GPS provides location information for identifying potential pothole locations.

## Features
- Road shock detection
- GPS location tracking
- Potential pothole identification
- Location data collection

## Technologies
- Embedded C/C++
- ESP32
- IoT
- GPS
